## 5. § 7150 subsection enumeration (for grader verified-subsection map ruling)

Adopted § 7150(b) contains **six** enumerated triggers, plus (b)(2)(A) HR-administrative carve-out. One-line gloss per subsection:

| Subsection | Gloss (glosses are editorial; the corpus row carries verbatim text only) |
|---|---|
| `§ 7150(a)` | Umbrella rule: risk assessment required **before** initiating any processing that presents significant risk to consumers' privacy as set forth in (b). |
| `§ 7150(b)(1)` | Selling or sharing personal information. |
| `§ 7150(b)(2)` | Processing sensitive personal information. |
| `§ 7150(b)(2)(A)` | Carve-out: HR-administrative processing of employee/contractor SPI for compensation, employment authorisation, benefits, reasonable accommodation, or wage reporting is exempt from the RA requirement; any other SPI processing remains covered. |
| `§ 7150(b)(3)` | Using ADMT for a significant decision concerning a consumer. |
| `§ 7150(b)(4)` | Automated inference/extrapolation of specified attributes based on **systematic observation** of an educational-programme applicant, job applicant, student, employee, or independent contractor. |
| `§ 7150(b)(5)` | Automated inference/extrapolation of specified attributes based on the consumer's presence in a **sensitive location** (with a delivery/transportation carve-out). |
| `§ 7150(b)(6)` | Processing PI the business **intends to use to train** an ADMT for a significant decision, or to train facial-recognition, emotion-recognition, or other identity / physical / biological identification-or-profiling technology. |
